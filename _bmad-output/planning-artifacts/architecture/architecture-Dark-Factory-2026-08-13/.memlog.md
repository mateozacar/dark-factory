- (version) FastAPI 0.141.1, Python 3.13, pytest 8.x, pytest-anyio, httpx 0.28.1 — verified 2026-08-13
- (decision) AD-1 Framework: FastAPI 0.141.1 on Python 3.13 — auto Swagger UI 5.x at /docs, OpenAPI 3.1; prevents framework fragmentation
- (decision) AD-2 Architecture pattern: Clean/Hexagonal 4-layer — domain/application/infrastructure/interface; domain has zero FastAPI/Pydantic imports; dependency direction inward only
- (decision) AD-3 Bounded context: single context 'earthquake' for v1 — Earthquake entity, Magnitude/Depth/Coordinates value objects, EarthquakeFilter
- (decision) AD-4 TDD discipline: tests written first always; tests/ mirrors src/ structure; pytest + anyio + httpx ASGITransport; Red-Green-Refactor
- (decision) AD-5 USGS integration: Port/Adapter — EarthquakeRepository abstract interface in domain/, USGSAdapter in infrastructure/usgs/; domain never imports httpx or USGS URLs
- (decision) AD-6 Response format: Accept header negotiation — application/json (simplified, default) vs application/geo+json (native USGS GeoJSON); single endpoint, no format duplication
- (decision) AD-7 API versioning: URL prefix /api/v1/ on all endpoints — prevents breaking changes hitting consumers without version control
- (decision) AD-8 Stateless proxy: no database, no cache, no persistence in v1 — every request proxied directly to USGS; prevents accidental stateful drift
- (decision) AD-9 Deployment: Render free tier (demo-appropriate; sleeps after 15min idle — acceptable for live demo); CI on every PR via GitHub Actions; CD on merge to main
- (decision) AD-10 Config: pydantic-settings + environment variables only; .env.example documents all vars; no hardcoded URLs or secrets
- (decision) AD-11 Package manager: uv (fast, modern Python package manager); pyproject.toml as single source of truth for deps and tooling
- (event) ARCHITECTURE-SPINE.md distilled from memlog; status set to final
