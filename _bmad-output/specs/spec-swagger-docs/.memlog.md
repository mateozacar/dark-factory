topic: Enrich OpenAPI/Swagger metadata so /docs is a complete, self-service API reference
updated: 2026-08-13T12:29
---

- (note) FastAPI already auto-generates /docs (Swagger UI) and /redoc; no additional packages needed per AD-1. main.py has title/description/version set. The gap is enriched metadata: endpoint summaries, response examples, error responses, tag descriptions.
- (decision) Scope: enrich OpenAPI metadata only — no functional changes, no new packages, no UI customization.
- (capability) CAP-1: Every public endpoint has summary, description, and documented responses in OpenAPI spec. SUCCESS: GET /openapi.json shows summary+description+responses on every operation.
- (capability) CAP-2: GET /api/v1/earthquakes includes a concrete GeoJSON FeatureCollection example in its 200 response schema. SUCCESS: Swagger UI renders the example under the 200 section.
- (capability) CAP-3: Endpoints that proxy USGS document a 502 error response. SUCCESS: OpenAPI spec for GET /api/v1/earthquakes includes a 502 response entry.
- (capability) CAP-4: Tag groups have descriptions in the FastAPI openapi_tags config. SUCCESS: /docs shows tag-level description above each endpoint group.
- (constraint) All metadata added via FastAPI built-ins (summary, description, responses, openapi_extra, openapi_tags) — zero new packages.
- (constraint) No changes to endpoint signatures, response structures, or HTTP behavior — OpenAPI enrichment only.
- (decision) Non-goals: no custom Swagger UI theme/favicon, no ReDoc customization, no auth on /docs, no expansion of stubs (/recent, /{id}) beyond documenting their stub status.
- (decision) Success signal: developer opens /docs, reads descriptions, sees example response on earthquake list, and can execute the request from the browser without any other docs.
- (event) Pass 1 Coherence: CAP-1 through CAP-4 each have intent+success. Intents describe WHAT not HOW. Constraints bend decisions (no new packages, no functional changes). Non-goals explicit (4 items). Success signal is demonstrable. IDs stable. PASS.
- (event) Pass 2 Preservation: all load-bearing source claims landed — FastAPI built-in Swagger noted, AD-1 referenced, endpoint list from architecture spine covered, stub status for /recent and /{id} preserved. No wrapper-ceremony drops. PASS.
